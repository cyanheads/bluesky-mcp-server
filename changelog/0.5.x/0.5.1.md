# 0.5.1 — 2026-09-25

A response that fits the budget is unchanged apart from the escaping and the new verification fields; `structuredContent` carries every user-authored string raw.

## Added

- **48,000-byte response budget** per surface on `bsky_search_posts`, `bsky_get_feed`, `bsky_get_author_feed`, and `bsky_get_post_quotes`: an overflowing page is re-requested at the `limit` that fits and returned whole with `budgetCapped: true`, so its cursor resumes at the first post left out. ([#26](https://github.com/cyanheads/bluesky-mcp-server/issues/26))
- **`bsky_get_post_thread` budget cut** keeps the target, parents nearest-first, then replies level by level, reports `budgetCapped` / `budgetOmitted` in enrichment, and marks the frontier with `budgetOmittedReplyUris`, `budgetOmittedReplies`, and `budgetOmittedParents` — fetching those AT-URIs reads everything left out. ([#26](https://github.com/cyanheads/bluesky-mcp-server/issues/26))
- **`verification`** on `bsky_get_profile` and `bsky://profile/{actor}`: `verifiedStatus`, `trustedVerifierStatus`, and each issuance with its issuer, record AT-URI, `isValid`, and `createdAt`. `bsky_search_actors`, `bsky_get_follows` (entries and subject), and post authors on the five post tools carry the two statuses on the DID line; absent when Bluesky sent none. ([#30](https://github.com/cyanheads/bluesky-mcp-server/issues/30))

## Fixed

- **`bsky_get_trending`** names a trend by its `topic` when the display name is blank or folds to nothing, instead of rendering `****` as a thematic break. ([#48](https://github.com/cyanheads/bluesky-mcp-server/issues/48))

## Security

- **Bluesky-authored text in `content[]` is escaped** wherever CommonMark or raw HTML would act on it — emphasis, links, images, code, lists, headings, tags, and entities in quoted and inline user text display as written. `snake_case`, URLs, `a < b`, and `AT&T` pass through unchanged, and a leading `>` still nests. ([#31](https://github.com/cyanheads/bluesky-mcp-server/issues/31))
- **Every user-text blockquote ends before the next server line**, so a rendering client no longer folds a post's counts, `Created:`, link-card, quoted-post, or `**Labels:**` line into the user's quote. ([#47](https://github.com/cyanheads/bluesky-mcp-server/issues/47))

## Dependencies

- Added dev-dependencies `commonmark` ^0.31.2 and `@types/commonmark` ^0.27.10 — the CommonMark reference parser the escaping and quote-boundary tests render through.
