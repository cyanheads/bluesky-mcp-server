# 0.6.0 — 2026-10-22

## Added

- **`bsky_search_feeds`**: Add `bsky_search_feeds` for keyless feed-catalog discovery. Uses an unstable upstream catalog API; pass returned feed URIs to `bsky_get_feed`. (#53)
- **Profile links**: Return ordered profile buttons with record identifiers, complete destinations, optional titles/icons, and labels through the profile tool and resource. (#52)
- **Quote ordering**: `bsky_get_post_quotes` accepts `sort: latest|top`, returns the applied sort, and preserves it through pagination and budget refetches; `top` follows Bluesky's descending like count. (#56)

## Changed

- **Read limits**: Clamp oversized limits, reply depth, and parent height to existing caps, with composed notices, logs, and a counter; `BLUESKY_CLAMP_READ_LIMITS=false` restores strict rejection. (#54)
- **Build and packaging**: Bun tooling and container images 1.4.2 → 1.4.4; synchronize framework guidance and exclude development sources from MCPB bundles.

## Fixed

- **Post facets**: Preserve UTF-8 byte ranges, complete links, mention DIDs, tags, extension variants, and forward metadata on both response surfaces, including quoted records and budget measurements; malformed known features reject. (#51)
- **Feed exhaustion**: Empty terminal continuations report traversal exhaustion instead of first-page no-data guidance. (#55)
