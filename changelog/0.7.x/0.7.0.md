# 0.7.0 — 2026-11-02

## Added

- **`bsky_get_post_interactions`** lists accounts that liked or reposted a post, with pagination, optional account creation dates, separate like timestamps, and counter-completeness guidance (#65).
- **`bluesky-guide`** ships research workflows through plugin installs, npm, Docker, MCPB, and the keyless `skill://bluesky-guide/SKILL.md` resource.
- **Actor metadata** retains optional account creation timestamps and label provenance in actor search and social graph results (#62).
- **Profile metadata** exposes supplied associated list, feed, and starter-pack counts and labeler status on the profile tool and resource, preserving zero, false, and empty objects (#63).

## Changed

- **Packaging** retains SDK skill runtime modules while pruning dependency authoring documents and build-only files from MCPB bundles; validates published guides and root plugin metadata.
- **Development tooling** synchronizes framework guidance, refreshes issue templates, and distinguishes installed direct dependencies from vulnerable transitive copies in audit output.

## Fixed

- **Feed catalog cursors** return non-retryable `invalid_cursor` with restart guidance for the catalog's recognized malformed-cursor responses (#59).
- **Video alt text** survives direct and nested embeds and renders as literal quoted text (#60).
- **Thread references** reject non-post AT-URI collections locally with collection-specific recovery (#61).
