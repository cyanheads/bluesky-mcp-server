# 0.8.0 — 2026-11-11

## Added

- Add `bsky_get_list` for list and starter-pack discovery, metadata, and paged membership (#64).
- **`bsky_get_feed`** reads posts and reposts from list AT-URIs and Bluesky list URLs.

## Changed

- **Bun** requires 1.4.4 or later.
- **Bluesky guide** documents how to discover a curated group and follow its member and feed references.
- **Development tooling** syncs framework skills, packaging checks, and release scripts.

## Removed

- **Client error data** drops captured upstream `error.data.body` and `error.data.responseBody`. Status, code, and typed reasons remain available.

## Fixed

- **Markdown rendering** avoids repeated scans when escaping URL delimiters in Bluesky text.
- **MCPB packaging** preserves nested SDK runtime modules during dependency cleanup.

## Dependencies

- `@cyanheads/mcp-ts-core` ^0.13.18 → ^0.13.22
- `@biomejs/biome` 2.6.4 → 2.6.6
- `vitest` ^5.0.5 → ^5.1.0
