# 0.3.0 — 2026-07-31

## Added

- **`renderEmbedLines()`** now emits a quoted post's **CID** beside its AT-URI (`💬 Quoted post: \`at://...\` | CID: \`bafy...\``), the same `AT-URI | CID` pair `renderPostLines()` already emits for the post doing the quoting. `cid` was already declared on the `record` embed and reached `structuredContent`; only `content[]` was missing it. Omitted when the quote slot holds an unreadable or non-post record (`recordKind` set), where `cid` is often empty. ([#24](https://github.com/cyanheads/bluesky-mcp-server/issues/24))
- **`renderLabelList()`**, shared by `bsky_get_profile` and the post renderer, now backs every post label, so `content[]` carries the labeler DID (`src`) and application time (`cts`) beside the value — previously value-only. `bsky_search_posts` and `bsky_get_author_feed`'s `PostSchema.labels` now declare `src`/`cts`, matching what `bsky_get_profile` and the passthrough `bsky_get_post_thread` node already exposed. ([#24](https://github.com/cyanheads/bluesky-mcp-server/issues/24))

## Changed

- **BREAKING:** `bsky_get_post_thread`'s post `author` narrows from the full `profileViewBasic` (which carried the account's own `createdAt`, moderation `labels`, and `pronouns`) to four fields — `did`, `handle`, `displayName?`, `avatar?`. The tool's node schema is `passthrough()`, so this is a real change to what reaches `structuredContent` for this tool. `bsky_search_posts` and `bsky_get_author_feed` are unaffected: their `PostSchema.author` was already a closed object exposing exactly these four fields, so the same normalization change is a no-op there. Account-level detail is a `bsky_get_profile` lookup away. ([#24](https://github.com/cyanheads/bluesky-mcp-server/issues/24))
- No tool's advertised `inputSchema`/`outputSchema` in `tools/list` changed. The removed embed fields and the narrower post author were documented only in Zod `.describe()` text on `passthrough()` schemas, never in the schema structure — a structural diff of `tools/list` between this release and the last shows zero property removals.

## Removed

- **`Embed.images[].aspectRatio`**, **`Embed.video.aspectRatio`**, and **`Embed.external.thumb`** are no longer normalized, so they no longer reach `structuredContent` — neither channel rendered them in `content[]`. `aspectRatio` describes pixel geometry of an asset the reader cannot see; `thumb` is a preview of a link card whose `uri`/`title`/`description` are already carried. See `docs/design.md` decision 20 for the measurements behind each call. ([#24](https://github.com/cyanheads/bluesky-mcp-server/issues/24))
